Original

for i in range(n):
    for j in range(i+1, n):
        if a[i] + a[j] == t:
            return [i, j]

Suggested

seen = {}
for i, x in enumerate(a):
    if t - x in seen:
        return [seen[t - x], i]
    seen[x] = i

O(n²) → O(n) time, O(1) → O(n) space. Trades memory for one pass.

Transparency

What's real in this build, and what's simulated.

This is a frontend-only build with no backend, database or AI model. Here's exactly what that means.

Code review
Rule-based checks run in your browser: pattern matching for risky calls, loop-nesting analysis for complexity. Results are labelled demonstration and are not AI analysis.
Running code
Nothing is compiled or executed. Sample test cases show expected output only. Real execution needs a separate sandboxed service.
Accounts
Sign-in opens a local demo session. No credentials are verified, sent, or stored.
Progress
Starts at zero and only reflects what you do here. It's saved in this browser's storage.

Practice problems sourced from the Curious Freaks Coding Sheet. Frontend demonstration. No real AI analysis takes place.
